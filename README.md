# smx0222 · Sistemes Operatius Monolloc

Teoria interactiva del mòdul 0222 (CFGM SMX), publicada amb GitHub Pages.

| Carpeta | Contingut |
|---|---|
| `teoria-p1/` | Projecte 1 · RA1 · Anatomia d’un sistema operatiu |
| `teoria-p2/` | Projecte 2 · RA5 · Virtualització (properament) |
